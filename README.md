BidWise is a secure and efficient digital marketplace platform that enables users to participate in online bidding for various products and services. The platform provides a transparent environment where sellers can list items and buyers can place competitive bids in real time. BidWise focuses on security, reliability, and ease of use to ensure a seamless auction experience for all users.

The system is designed to simplify the traditional auction process by bringing it to an online platform with automated bidding, secure authentication, and real-time updates.

Technologies Used :- 
Frontend :- React.js, HTML, CSS,  JavaScript 
Backend :- NNode.js, Express.js
Database :- MongoDB
